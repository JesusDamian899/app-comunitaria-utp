# App Comunitaria UTP - Sistema Vecinal

Aplicación comunitaria integral para la gestión vecinal, seguridad ciudadana y apoyo solidario.

## Estado del Proyecto
- **Fase 4 Completada**:
  - Muro Solidario y Directorio de Servicios de Confianza.
  - CRUD completo (Crear, Leer, Editar, Eliminar) para publicaciones de servicios y favores.
  - Persistencia híbrida y local con **SQLite** (`expo-sqlite`) y sincronización en la nube con **Supabase**.
  - Alerta de Emergencia SOS, mapa de cuadrantes y asamblea vecinal offline-first.
  - Protección y deduplicación estricta de registros y claves en React.
